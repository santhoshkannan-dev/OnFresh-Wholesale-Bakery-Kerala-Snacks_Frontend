# OnFresh-Wholesale-Bakery-Kerala-Snacks_Frontend

**OnFresh** — Wholesale Bakery & Traditional Kerala Snacks (Vandiperiyar, Idukki, Kerala, India).

Frontend application built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## Features

- **Dual B2C Retail & B2B Wholesale Commerce:**
  - Individual retail shopping with package sizes (250g, 500g, 1kg) and direct checkout.
  - Dedicated Wholesale Business Portal with tiered wholesale pricing, MOQs, and onboarding.
- **Editorial Design System:**
  - Typography: Bricolage Grotesque (editorial headlines) & Plus Jakarta Sans (body).
  - Authentic bakery warm cream and dark chocolate palette with Kerala spice accents.
  - Micro-interactions, dynamic cart drawer, search overlay, and mega menu.
- **Unified Customer Account:**
  - Order history, invoice downloads, saved addresses, and wholesale upgrade applications.
- **Staff & Admin Operations Dashboard:**
  - Analytics, inventory alerts, production batches, raw materials, and invoice management.

---

## Tech Stack

- **Framework:** Next.js (App Router, Turbopack)
- **Styling:** Tailwind CSS (v4)
- **Icons & Animation:** Lucide React, Motion, Canvas-Confetti
- **Language:** TypeScript

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env.local`:
```bash
NEXT_PUBLIC_API_URL=http://localhost:8000/api
```

### 3. Run Development Server
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

### 4. Build for Production
```bash
npm run build
npm run start
```
